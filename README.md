# ANN Classification for Customer Churn

This project implements an **Artificial Neural Network (ANN)** for predicting customer churn. It uses preprocessed data, trained models, and encoders to classify whether a customer is likely to churn.


## 🚀 Features

- Customer churn prediction using ANN.
- Supports preprocessing using saved encoders and scalers.
- Logs training and prediction results for analysis.
- Easy-to-run Python scripts for training and inference.


  ## 🧰 Technologies Used

- **Python** – Main programming language.  
- **TensorFlow / Keras** – For building and training the ANN models.  
- **Pandas & NumPy** – Data manipulation and numerical computations.  
- **Scikit-learn** – Preprocessing (scalers, encoders) and evaluation metrics.  
- **Matplotlib / Seaborn** – Data visualization and plotting.  
- **Pickle** – Saving and loading encoders and scalers.  
- **H5 Format** – Storing trained ANN model (`model.h5`).
